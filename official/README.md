# Official plugins

[Unnamed Tracking PWA](pwa/README.md) is maintained official functionality,
currently **0.0.1** during integration. Its signed public release is gated on a
new official publisher identity being provisioned. Unsigned development previews
are explicitly unverified and receive no Official trust badge.

Official plugins are maintained user-facing features. Demonstrations remain in
`examples/` and use separate demo signing identities. Valid signature and official
status are distinct; every plugin still requires its declared permissions.
