# Official plugins

[Jellyfin Media Sync](jellyfin-media-sync/README.md) starts at **0.0.1**, an official
preview under test. Its new ID is `official.jellyfin-media-sync`. It remains
unreleased in the signed catalogue until publisher scope and release testing are
complete. Version 1.0 will follow validation and an explicit release decision.

The separate [Jellyfin demo](../examples/jellyfin-media-sync/README.md) remains an
example. Official status gives no extra grants, sandbox exemptions or host APIs.
