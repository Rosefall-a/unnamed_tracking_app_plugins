# Unnamed Tracking official example plugins

Independent reference plugins for Plugin API v1. Host/runtime/gateway implementation remains in the main application repository.

Examples:
- examples/lifecycle — startup, configuration and persistent state.
- examples/events — user-scoped event subscription and bounded delivery.
- examples/ui-api — declarative native UI and gateway API requests.
- examples/advanced — optional dependencies, scoped identity and storage.

Each example has a v1 manifest, tests, and a reproducible .utp package builder.
